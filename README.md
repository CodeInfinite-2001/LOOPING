# LOOPING - Screen Recorder & Video Splitter 🎬

A powerful, 100% offline, cross-platform Desktop Screen Recorder and Video Splitter for **Windows** and **Linux**.

---

## 🇬🇧 English Overview

This software is designed for Windows and Linux computers. It can be independently installed as a Windows executable (`.exe`) or a Linux package and used completely offline.

**No command-line (CMD) commands are required to use the application!**

### Main Features

1. **Full Screen Recording**
   - Record your entire monitor screen with ease.

2. **Select Area / Region Recording**
   - Select and record only a specific area of your screen by dragging to define a custom recording region.
   - Includes pixel-accurate canvas cropping and interactive resizing and dragging handles for precise area selection.

3. **Sound Options**
   - 🔇 **No Sound:** Record video without any audio.
   - 🎤 **Microphone Only:** Record your voice using a selectable microphone device, with a live audio level VU meter.
   - 🔊 **System Audio:** Capture sounds playing on your computer, including YouTube videos, games, and music.
   - 🎙️+🔊 **Both:** Record microphone input and system audio simultaneously, mixed into a single recording.

4. **Built-in Video Splitter**

   - Once recording is completed, the video can be finalized into a standard format and transferred directly to the Video Splitter.

   - **Mode 1 – Cut Markers:**
     - Place multiple markers at your preferred points in the video.
     - Automatically split the video into multiple sections (Part 1, Part 2, Part 3, etc.).
     - Uses lossless FFmpeg processing to split videos quickly without reducing their original quality.

   - **Mode 2 – Trim Start & End:**
     - Select the starting and ending points to extract only the required section of a video.

   - **Mode 3 – Equal Parts:**
     - Automatically divide a video into equal-length sections (e.g., 2, 3, or 5 parts).

   - Supports importing and splitting existing video files in various formats, including `.mp4`, `.webm`, `.mkv`, and more.

5. **Mini Floating Pill Bar & Hotkeys**

   - During recording, the main application window minimizes into a compact floating control bar displayed on the screen.
   - **F9:** Start or stop screen recording (Global Shortcut).
   - **F10:** Pause or resume screen recording.

6. **Language Toggle**
   - Easily switch between English and Sinhala using the built-in language selection option.

## 📦 Installable Executables

The application is ready to install and use. The generated files are located in:

`D:\Projects\screen recorder\release\`

### 1. Windows Installer (.exe)

- **File:** `release\LOOPING Setup 1.0.0.exe`
- Install the application just like any standard Windows software.
- Simply double-click the installer to begin installation.
- Supports creating a Desktop Shortcut for convenient access.

### 2. Windows Portable Version (.exe)

- **File:** `release\LOOPING 1.0.0.exe`
- No installation required.
- Simply double-click the executable to launch the application.
- Can be run directly from any location.

### 3. Linux Package

- **File:** `release\looping-1.0.0.tar.gz`
- **Additional folder:** `release\linux-unpacked\looping`

Extract the `.tar.gz` archive and run the `looping` executable to launch the application.

## 🇱🇰 සිංහලෙන් විස්තරය (Overview in Sinhala)

### ප්‍රධාන පහසුකම් (Features):
1. **Full Screen Record**: ඔබේ මොනිටරයේ සම්පූර්ණ තිරයම පටිගත කිරීමේ හැකියාව.
2. **Select Area / Region Record**: තිරයේ ඔබට අවශ්‍ය කොටස පමණක් drag කර select කර නිශ්චිත ප්‍රමාණය (Custom Area) පටිගත කිරීම. Pixel-accurate canvas cropping සහ interactive resize/drag handles සහිතයි.
3. **Sound Options (ශබ්ද විකල්ප)**:
   - 🔇 **No Sound (ශබ්ද රහිතව)**: වීඩියෝව පමණි.
   - 🎤 **Microphone Only**: ඔබේ කටහඬ පමණක් පටිගත කිරීම (Microphone Device තෝරාගත හැක, Live Level VU Meter සහිතයි).
   - 🔊 **System Audio**: පරිගණකයේ වාදනය වන ශබ්ද (YouTube, Games, Songs).
   - 🎙️+🔊 **Both (දෙකම එකට)**: මයික්‍රෆෝනය සහ පරිගණක ශබ්දය දෙකම එකට mix කර පටිගත කිරීම.
4. **Built-in Video Splitter (වීඩියෝ කපන පහසුකම)**:
   - පටිගත කිරීම අවසන් වූ සැනින් වීඩියෝව standard format එකකට finalize වී Video Splitter වෙත ගෙන යා හැක.
   - **Mode 1 (Cut Markers)**: වීඩියෝවේ කැමති තැන් වලට Markers තබා එකවර කොටස් කිහිපයකට (Part 1, Part 2, Part 3) කපා වෙන් කිරීම (Lossless FFmpeg - තත්පර ගණනකින් කිසිදු quality අඩුවීමකින් තොරව සිදුවේ).
   - **Mode 2 (Trim Start & End)**: වීඩියෝවේ මුල සහ අග ලකුණු කර අවශ්‍ය කොටස පමණක් කපාගැනීම.
   - **Mode 3 (Equal Parts)**: වීඩියෝව සමාන කොටස් වලට (උදා: 2, 3, 5) එකවර බෙදීම.
   - පරිගණකයේ ඇති ඕනෑම වීඩියෝවක් (`.mp4`, `.webm`, `.mkv`, etc.) ඇතුළත් කර Split කිරීමේ හැකියාව.
5. **Mini Floating Pill Bar & Hotkeys**:
   - රෙකෝඩ් වන විට ප්‍රධාන කවුළුව කුඩා වී කුඩා Floating Bar එකක් තිරය මත පෙන්වයි.
